# Credits

D8Engine is FFmpeg (https://ffmpeg.org), built by BtbN (https://github.com/BtbN/FFmpeg-Builds).
It statically links many open-source libraries, each under its own license, including:
x264, x265, libvpx, libaom, SVT-AV1, libvorbis, libopus, LAME (libmp3lame), libwebp,
FreeType, HarfBuzz, libass, zimg and others. Run `D8Engine.exe -buildconf` for the full list.
